# Import Substitution Priority

Python data analysis application for prioritizing product categories for import substitution based on Russian foreign trade statistics.

## Project Structure

- `data/` - input datasets
- `docs/` - project notes and documentation
- `src/` - application source code
- `tests_ipynb/` - notebook-based checks for pipeline modules
- `outputs/` - generated reports, charts, and exports
- `main.py` - application entry point
- `run_app.bat` - Windows launcher

## Core Stack

- Python
- pandas
- numpy
- matplotlib
